# Participant trip history

The dashboard distinguishes active trips from archived trip history.
Both views use the authenticated member's memberships, so regular
participants can browse their archived trips without admin privileges.

The history view displays archived trip cards with a historical status,
uses dedicated empty-state messaging, and omits the new-trip prompts.
Every trip remains accessible through the existing details and overview
links. Archiving does not remove membership, photos or payment records.
