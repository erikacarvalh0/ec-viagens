# Private trip photo gallery

Trip members can upload JPEG or PNG images up to 5 MB from
`/trips/<tripId>/photos`. Files are validated by their magic bytes and
stored in a **private AWS S3 bucket**. Storage keys are generated by
the server and never supplied by the client.

Configure these server-side environment variables:

```env
S3_BUCKET="private-trip-photos"
S3_REGION="us-east-1"
S3_ACCESS_KEY_ID="..."
S3_SECRET_ACCESS_KEY="..."
```

The S3 credentials must be restricted to `s3:PutObject` and
`s3:GetObject` on the dedicated bucket prefix. Block all public
access. Do not set a public bucket policy.

Images are served through an authenticated, trip-scoped API endpoint
with private no-store caching. The initial gallery shows up to 100
photos; pagination, deletion, thumbnails, EXIF stripping, and
malware scanning are future improvements.

The upload endpoint checks the declared content length and file size.
For production deployments, also configure a request-body size limit
at the ingress/proxy to reject oversized multipart bodies before parsing.
