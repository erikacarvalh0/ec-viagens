# Initial PostgreSQL migration baseline

The initial migration creates the original eleven tables and five enums. The existing subsequent migration creates `PasswordResetToken` separately. **Fresh empty databases** can run `npx prisma migrate deploy` in timestamp order. For **existing databases created using `prisma db push`**, do not apply this baseline to populated tables: first reconcile actual schema and mark the baseline as applied using `prisma migrate resolve --applied 20261115000000_initial_baseline` only after review. Verify migration status and schema drift before production rollout. Integration CI must validate migrations against a fresh PostgreSQL database before declaring production readiness.
